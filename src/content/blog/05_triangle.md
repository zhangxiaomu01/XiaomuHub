这是我「图形学基础」系列的第四篇。第一篇讲叉积时埋了个伏笔：三角形的法线、面积、点在三角形内外的判定，都是叉积的用武之地。本篇把这些伏笔一并兑现——顺便请出三角形身上最优雅、出场率也最高的概念：**重心坐标**。

> 三角形是图形学里**最基础、最重要的图元**：所有多边形网格都能拆成三角形；光栅化、光线追踪、碰撞检测、法线插值、纹理映射……几乎所有算法都以三角形为基本单位。
> 本篇聚焦三角形的四个核心属性：**定义**、**法向量**、**面积**、**重心坐标**。

为什么偏偏是三角形？多边形不行吗？——因为**三点必然共面**（四边形四个顶点可能不共面，光栅化时「像素落在哪个平面里」都说不清）；因为**三角形必然是凸的**（扫描线填充、裁剪算法都简单可控）；因为**任何多边形都能拆成三角形**（GPU 只需要伺候好这一种图元，硬件才能做得极简极快）。所以建模软件里再随意的多边形网格，送进渲染管线前都会被三角化，GPU 光栅化的单位从头到尾只有三角形。

## 一、定义

### 1.1 顶点与边向量

三角形由**三个不共线的顶点** $v_0, v_1, v_2$ 唯一确定。不过实际做计算时，更常打交道的是顶点相减得到的**边向量**（第一篇的老规矩：两点相减得向量）：

$$
\mathbf{e_0} = v_1 - v_0, \quad \mathbf{e_1} = v_2 - v_0, \quad \mathbf{e_2} = v_2 - v_1
$$

其中 $\mathbf{e_0}$、$\mathbf{e_1}$ 都从 $v_0$ 出发——后面求法线、算面积、解重心坐标，用的都是这两条边。

### 1.2 退化三角形：三点共线

「不共线」三个字是前提。**不共线的三点确定唯一平面**；反过来，若三点共线，三角形就退化成一条线段：叉积变零向量、面积 $=0$，法向量和重心坐标统统失去意义。后面 `barycentric()` 的实现里，用分母 $\text{denom}\approx 0$ 检测的就是这种退化情况。

### 1.3 有向面积：绕序决定朝向

叉积 $\mathbf{e_0}\times\mathbf{e_1}$ 的模长是「面积的两倍」，而叉积本身是个**向量**——它朝向平面的哪一侧，由**顶点绕序**决定，这就是「有向」的含义：同一个三角形，把任意两个顶点调换顺序，法向量立刻反向。图形学里「正面 / 背面」「逆时针 / 顺时针」这一整套约定，根源都在这里（第二节展开）。

### 1.4 代码表示：Triangle

三角形的全部状态就是三个顶点，其余属性全是「现算现用」。一个典型的结构体长这样，还是系列里熟悉的模板套路：

```cpp
template <typename T>
struct Triangle {
    Vec3<T> v0, v1, v2;    // 三个顶点：全部状态

    Vec3<T> normal() const;       // 单位法向量
    T      area() const;          // 面积
    Vec3<T> centroid() const;     // 几何中心（三顶点平均）
    void   barycentric(const Vec3<T>& p, T& u, T& v, T& w) const;  // 重心坐标
};

using Trianglef = Triangle<float>;
using Triangled = Triangle<double>;
```

要点：

- `v0 / v1 / v2` 三个 `Vec3` 就是全部成员，没有冗余存储；
- `normal()`、`area()` 都是一次叉积的产物（第二、三节）；
- `barycentric()` 是本篇的主角（第四节）。

## 二、法向量

### 2.1 叉积求法线

第一篇讲叉积时说过：**叉积的结果垂直于两个输入向量所在的平面**。把三角形的两条邻边喂给它，得到的正好是三角形所在平面的法线方向，归一化后即单位法向量：

$$
\mathbf{n} = \text{normalize}\big((v_1 - v_0) \times (v_2 - v_0)\big)
$$

```cpp
Vec3<T> normal() const {
    return cross(v1 - v0, v2 - v0).normalized();
}
```

一个叉积同时给出「方向（法线）」和「大小（面积的两倍）」——这就是三角形离不开叉积的原因。

### 2.2 右手定则与顶点绕序

法线朝平面的哪一侧？**右手定则**：右手四指从 $\mathbf{e_0} = v_1-v_0$ 的方向，以小于 $180°$ 的夹角弯向 $\mathbf{e_1} = v_2-v_0$ 的方向，大拇指的指向就是 $\mathbf{n}$ 的方向。

于是**顶点绕序**直接决定法线朝向：$v_0 \to v_1 \to v_2$ 一种顺序得到一个方向，任意交换两个顶点（绕序反转），法线立刻掉头反向。

### 2.3 正面与背面：CCW vs CW

从法线指向的那一侧观察三角形：

- **CCW（逆时针绕序）**：$v_0 \to v_1 \to v_2$ 呈逆时针排列 → 该面朝向观察者，是**正面**；
- **CW（顺时针绕序）**：呈顺时针排列 → 该面背离观察者，是**背面**。

**OpenGL 默认约定**：右手坐标系下，OpenGL 默认将 CCW 绕序视为正面（`glFrontFace(GL_CCW)`），CW 面视为背面并默认开启背面剔除（`GL_CULL_FACE`）。因此在建模时，三角形顶点应按「从 mesh 外部观察呈逆时针」的顺序排列，才能保证法线朝外、正面可见。

> ⚠️ DirectX 默认把 **CW（顺时针）**当正面，与 OpenGL 正好相反——跨 API 移植模型时的经典翻车点。

```cpp
using namespace gm;

// XY 平面上的直角三角形，CCW 绕序
Trianglef tri(Vec3f(0,0,0), Vec3f(2,0,0), Vec3f(0,2,0));
Vec3f n = tri.normal();   // (0, 0, 1) —— 法线指向 +Z，正面朝向观察者
```

## 三、面积

### 3.1 公式与推导

**核心公式**：叉积的模长等于以两条邻边为邻边的**平行四边形面积**，三角形面积取一半：

$$
S = \frac{1}{2} \big| (v_1 - v_0) \times (v_2 - v_0) \big|
$$

```cpp
T area() const {
    return T(0.5) * cross(v1 - v0, v2 - v0).length();
}
```

**为什么？** 设两邻边夹角为 $\theta$，第一篇的叉积模长公式：

$$
|\mathbf{a} \times \mathbf{b}| = |\mathbf{a}|\,|\mathbf{b}|\sin\theta
$$

底 $\times$ 高：底是 $|\mathbf{a}|$，高是 $|\mathbf{b}|\sin\theta$（斜边往垂直方向投影）——这正是平行四边形面积，三角形是它的一半。

### 3.2 优势：三维空间免投影

叉积法求面积有个杀手锏：**三维空间直接算，无需先投影到二维**。三角形以任何姿态躺在任何平面上，一个叉积搞定。相比之下，平面几何里的「底 × 高 ÷ 2」在三维里反而难用——你得先找到高在哪。

## 四、重心坐标 (Barycentric Coordinates)

重心坐标是三角形相关**最重要的概念之一**，应用遍布：光栅化中的属性插值（颜色、法线、UV）、光线追踪的命中判定、有限元插值……一句话：**三角形所在平面上任何一点的属性，都能用重心坐标从三个顶点插值出来**。

### 4.1 定义：三个顶点的加权平均

三角形所在平面内任一点 $P$，都可以表示为三个顶点的**加权平均**：

$$
P = \alpha\, v_0 + \beta\, v_1 + \gamma\, v_2
$$

其中权重满足归一化约束：

$$
\alpha + \beta + \gamma = 1
$$

$(\alpha, \beta, \gamma)$ 就是 $P$ 关于三角形 $(v_0, v_1, v_2)$ 的**重心坐标**。两个细节值得注意：

- 权重**不必局限在 $[0,1]$**——当点在三角形外部时，某些坐标会变成负数；
- 约束 $\alpha+\beta+\gamma=1$ 意味着三个权重只有两个自由度——平面上一个点两个坐标，正好对上。

### 4.2 几何意义：面积比

重心坐标有一个优美的几何解释——**子三角形与原三角形的面积之比**：

$$
\alpha = \frac{\text{Area}(P, v_1, v_2)}{\text{Area}(v_0, v_1, v_2)}, \quad
\beta = \frac{\text{Area}(v_0, P, v_2)}{\text{Area}(v_0, v_1, v_2)}, \quad
\gamma = \frac{\text{Area}(v_0, v_1, P)}{\text{Area}(v_0, v_1, v_2)}
$$

$\alpha$ 是「**对面**于 $v_0$ 的子三角形」的面积占比：$P$ 越靠近 $v_0$，对面那块子三角形越大，$\alpha$ 也越大。$\beta$、$\gamma$ 同理。

**特例验证**：

- 当 $P = v_0$ 时，子三角形 $(P, v_1, v_2)$ 就是原三角形本身 → $\alpha = 1,\ \beta = \gamma = 0$ ✓
- 当 $P$ 为重心时，三个子三角形面积相等 → $\alpha = \beta = \gamma = \tfrac{1}{3}$ ✓

### 4.3 推导：面积比 = 加权系数

**目标**：证明面积比定义 $\Longleftrightarrow$ $P = \alpha v_0 + \beta v_1 + \gamma v_2$（$\alpha+\beta+\gamma=1$）。

**第一步：建立向量关系。** 令 $\mathbf{e_0} = v_1 - v_0$，$\mathbf{e_1} = v_2 - v_0$，$\mathbf{e_2} = P - v_0$。若 $P$ 在三角形所在平面内，则 $\mathbf{e_2}$ 可以用 $\mathbf{e_0}$、$\mathbf{e_1}$ 线性表出：

$$
\mathbf{e_2} = P - v_0 = \beta\,(v_1-v_0) + \gamma\,(v_2-v_0) = \beta\,\mathbf{e_0} + \gamma\,\mathbf{e_1}
$$

移项整理得 $P = (1-\beta-\gamma)\,v_0 + \beta\, v_1 + \gamma\, v_2$，令 $\alpha = 1-\beta-\gamma$，正是重心坐标的表达式。

**第二步：面积比 = 权重。** 子三角形 $(v_0, P, v_2)$ 与原三角形 $(v_0, v_1, v_2)$ 共享底边 $\overline{v_0 v_2}$，面积比就等于「$P$ 到该底边的距离」与「$v_1$ 到该底边的距离」之比。而 $P$ 沿 $\mathbf{e_0}$（指向 $v_1$）方向的分量恰好是 $\beta$——离底边越远 $\beta$ 越大，面积比也越大，二者相等：$\text{Area}(v_0,P,v_2)/\text{Area}(v_0,v_1,v_2) = \beta$。$\gamma$ 同理，对应共享底边 $\overline{v_0 v_1}$ 的子三角形 $(v_0,v_1,P)$。

**第三步：归一化保证。** 三个子三角形 $(P,v_1,v_2)$、$(v_0,P,v_2)$、$(v_0,v_1,P)$ 恰好拼满原三角形（内部点显然；代数上对外部点同样成立），三块面积之和 $=$ 总面积，于是 $\alpha + \beta + \gamma = 1$。与第一步的约束吻合，推导闭合。

### 4.4 点在三角形内外的判定

由面积比的几何意义直接得到：

$$
P \text{ 在三角形内部} \iff \alpha \ge 0 \;\wedge\; \beta \ge 0 \;\wedge\; \gamma \ge 0
$$

又因 $\alpha = 1 - \beta - \gamma$，等价条件为：

$$
\beta \ge 0 \;\wedge\; \gamma \ge 0 \;\wedge\; \beta + \gamma \le 1
$$

判定细则：

- 某坐标 $= 0$ → 点在**边上**；
- 某坐标 $= 1$（另两个 $=0$）→ 点恰在**顶点**上；
- 某坐标 $< 0$ → 点在三角形**外部**。

> 还记得第一篇叉积那节的「同号法」吗？两种方法殊途同归：同号法只回答「在内 / 在外」，重心坐标法一次算出三个权重——判定内外只是顺手的事，算完还能接着做属性插值（见 4.6 节）。

### 4.5 高效实现：点积法

面积比法概念清晰，但按定义算要 4 次叉积（4 个三角形面积）。更高效的做法是**点积法**（出自 Christer Ericson《Real-Time Collision Detection》），只需 **5 次点积 + 1 次除法**。

**思路**：由 4.3 节第一步，$\mathbf{e_2} = \beta\,\mathbf{e_0} + \gamma\,\mathbf{e_1}$。这是一个向量方程、两个未知数——两边分别点乘 $\mathbf{e_0}$ 和 $\mathbf{e_1}$，把它变成标量的 2×2 线性方程组：

$$
\mathbf{e_2} \cdot \mathbf{e_0} = \beta\,(\mathbf{e_0}\cdot\mathbf{e_0}) + \gamma\,(\mathbf{e_1}\cdot\mathbf{e_0})
$$

$$
\mathbf{e_2} \cdot \mathbf{e_1} = \beta\,(\mathbf{e_0}\cdot\mathbf{e_1}) + \gamma\,(\mathbf{e_1}\cdot\mathbf{e_1})
$$

记 5 个点积为标量：

$$
d_{00} = \mathbf{e_0}\cdot\mathbf{e_0},\quad d_{01} = \mathbf{e_0}\cdot\mathbf{e_1},\quad d_{11} = \mathbf{e_1}\cdot\mathbf{e_1},\quad d_{20} = \mathbf{e_2}\cdot\mathbf{e_0},\quad d_{21} = \mathbf{e_2}\cdot\mathbf{e_1}
$$

$$
\begin{cases}
d_{20} = \beta\, d_{00} + \gamma\, d_{01} \\
d_{21} = \beta\, d_{01} + \gamma\, d_{11}
\end{cases}
$$

**用克拉默法则求解**，分母是系数矩阵的行列式：

$$
\text{denom} = d_{00}\, d_{11} - d_{01}\, d_{01}
$$

$$
\beta = \frac{d_{11}\, d_{20} - d_{01}\, d_{21}}{\text{denom}}, \qquad
\gamma = \frac{d_{00}\, d_{21} - d_{01}\, d_{20}}{\text{denom}}, \qquad
\alpha = 1 - \beta - \gamma
$$

> 当 $\text{denom} \approx 0$ 时，$\mathbf{e_0}, \mathbf{e_1}$ 线性相关（三点共线），是退化三角形，重心坐标无意义——代码此时返回 $(0,0,0)$ 兜底。

```cpp
void barycentric(const Vec3<T>& p, T& u, T& v, T& w) const {
    Vec3<T> e0 = v1 - v0;      // β 方向边
    Vec3<T> e1 = v2 - v0;      // γ 方向边
    Vec3<T> e2 = p  - v0;

    T d00 = dot(e0, e0);       // 5 个点积
    T d01 = dot(e0, e1);
    T d11 = dot(e1, e1);
    T d20 = dot(e2, e0);
    T d21 = dot(e2, e1);
    T denom = d00 * d11 - d01 * d01;

    if (std::fabs(denom) <= std::numeric_limits<T>::epsilon()) {
        u = v = w = T(0);      // 退化三角形：三点共线
        return;
    }
    v = (d11 * d20 - d01 * d21) / denom;  // β：v1 的权重
    w = (d00 * d21 - d01 * d20) / denom;  // γ：v2 的权重
    u = T(1) - v - w;                     // α：v0 的权重
}
```

**输出语义**：输出参数 `(u, v, w)` 分别是顶点 $(v_0, v_1, v_2)$ 的权重，即 $P = u\cdot v_0 + v\cdot v_1 + w\cdot v_2$。拿几个特殊点快速验证：

| 测试点 | $u$（$v_0$ 权重） | $v$（$v_1$ 权重） | $w$（$v_2$ 权重） |
|:------:|:----------------:|:----------------:|:----------------:|
| $P = v_0$ | 1 | 0 | 0 |
| $P = v_1$ | 0 | 1 | 0 |
| $P = v_2$ | 0 | 0 | 1 |
| 重心 | 1/3 | 1/3 | 1/3 |

### 4.6 应用：属性插值

重心坐标真正的威力在于**插值**：光栅化时，GPU 对三角形覆盖的每个像素算出重心坐标，再用它把三个顶点携带的属性（颜色、法线、UV）插值成像素属性——Gouraud / Phong 着色、纹理映射全靠它。

```cpp
using namespace gm;

Trianglef tri(Vec3f(0,0,0), Vec3f(2,0,0), Vec3f(0,2,0));
float u, v, w;

// ① 判定点是否在三角形内
Vec3f p(0.5f, 0.5f, 0);
tri.barycentric(p, u, v, w);
bool inside = (u >= 0 && v >= 0 && w >= 0);   // true

// ② 属性插值：已知三顶点颜色 c0 / c1 / c2，求 P 处颜色
Color c = u * c0 + v * c1 + w * c2;
```

光线追踪里，射线与三角形求交命中后，同样用重心坐标把顶点法线插值成命中点法线——同一份数学，到处复用。

## 五、几何中心（重心）

三个顶点的算术平均：

$$
C = \frac{v_0 + v_1 + v_2}{3}
$$

```cpp
Vec3<T> centroid() const {
    return (v0 + v1 + v2) / T(3);
}
```

它正是重心坐标为 $(\tfrac{1}{3}, \tfrac{1}{3}, \tfrac{1}{3})$ 的那个点（4.2 节的特例）——「重心坐标」的名字正来源于此。物理图像：三个顶点各挂一个等质量质点，这个点就是让整个系统平衡的支点。

## 六、概念速览

### 核心公式速查

| 属性 | 公式 | 要点 |
|---|---|---|
| 法向量 | $\mathbf{n} = \text{normalize}\big((v_1-v_0)\times(v_2-v_0)\big)$ | 右手定则定向，绕序一反法线就反向 |
| 面积 | $S = \tfrac{1}{2}\|(v_1-v_0)\times(v_2-v_0)\|$ | 叉积模长 = 平行四边形面积 |
| 重心坐标 | $P = \alpha v_0 + \beta v_1 + \gamma v_2$ | $\alpha+\beta+\gamma=1$，几何意义 = 面积比 |
| 内外判定 | $\alpha,\beta,\gamma \ge 0$ | 等价于 $\beta\ge0,\ \gamma\ge0,\ \beta+\gamma\le1$ |
| 几何中心 | $C = (v_0+v_1+v_2)/3$ | 即重心坐标 $(\tfrac13,\tfrac13,\tfrac13)$ 的点 |

### 必记口诀

- **法线看绕序**：右手定则定向；OpenGL 默认 CCW 为正面，DirectX 默认 CW——两套 API 相反。
- **面积半个叉积**：$S=\tfrac12|(v_1-v_0)\times(v_2-v_0)|$，三维空间免投影。
- **重心坐标 = 面积比**：三个子三角形各占原三角形的比例，权重和恒为 1。
- **在内判定看负号**：三个权重全非负即在内部；为 0 在边上，为 1 在顶点，为负在外面。
- **高效算法点积法**：5 次点积 + 克拉默法则解 2×2 方程组；$\text{denom}\approx 0$ 即退化三角形。
