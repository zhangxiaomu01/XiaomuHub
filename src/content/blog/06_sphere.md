## 一、定义：一张方程圈定一张曲面

### 1.1 中心与半径

球体由**中心** $C=(c_x,c_y,c_z)$ 与**半径** $r$ 唯一确定。换成更几何的说法：球面就是**到定点（球心）距离等于定长（半径）的点的全体**。两个参数——一个点、一个数——就说完了整张闭合曲面，没有比这更省的曲面定义了。

> 顺带一提：球大概是数学家最偏爱的形体。阿基米德最得意的发现正是球的度量（外切圆柱的体积是球的 $3/2$ 倍，见第四节），他遗嘱要求把「圆柱容球」图形刻在自己的墓碑上。

### 1.2 隐式方程与内外判定

空间中任一点 $P=(x,y,z)$ 在球面上，当且仅当它到中心的距离等于半径：

$$
\|P-C\| = r
$$

展开成代数形式，即球的**隐式方程 (Implicit Equation)**：

$$
(x-c_x)^2 + (y-c_y)^2 + (z-c_z)^2 = r^2
$$

由隐式方程可以直接判定点与球的位置关系：

$$
(x-c_x)^2 + (y-c_y)^2 + (z-c_z)^2
\begin{cases}
= r^2 & \text{点在球面上} \\
< r^2 & \text{点在球内部} \\
> r^2 & \text{点在球外部}
\end{cases}
$$

两个实用细节：

- **判定不用开方**：两边同平方，比较「距离平方 vs $r^2$」即可——正是第一篇说过的 `lengthSquared()` 省开方技巧，一次点积出结果；
- **推广成有符号距离**：令 $d(P) = \|P-C\| - r$，则球面上为 0、内部为负、外部为正。这就是**有向距离场 (SDF)** 的最简样例——ray marching 和几何布尔运算的地基，球是它们最经典的入门例子。

### 1.3 隐式 vs 显式：两种表示思路

上一篇的三角形（顶点枚举）和本篇的球（方程圈定），正好代表了几何表示的两大阵营：

| | 隐式表示（球） | 显式表示（三角网格） |
|---|---|---|
| 形式 | 方程 $f(P)=0$ | 枚举顶点 / 面 |
| 内外判定 | 代入方程，比较平方 | 重心坐标 / 叉积同号法 |
| 法线 | 解析式直接给出 | 边叉积 + 顶点插值 |
| 光滑度 | 天然完美光滑 | 近似，细分才平滑 |
| 布尔运算 | 容易（SDF 上 max/min 组合） | 很难（需重三角化） |
| 光栅化 | 不友好，需先三角化 | 友好，GPU 本职工作 |

一句话总结：**隐式擅长「判定」，显式擅长「绘制」**。球体是隐式阵营里最简单、最对称的代表——它的法线和光线求交都有解析解，这就是渲染教材都拿球开篇的原因；而参数方程（第二节）则是给隐式的球「补上」显式枚举能力的桥梁。

### 1.4 代码表示：Sphere

和 `Triangle` 一个套路：状态极简，属性现算现用。

```cpp
template <typename T>
struct Sphere {
    Vec3<T> center;   // 球心
    T       radius;   // 半径（默认构造：中心在原点，半径 1）

    Vec3<T> normalAt(const Vec3<T>& p) const;       // 球面上点 p 的单位法向量
    Vec3<T> pointOnSurface(T theta, T phi) const;   // 球坐标采样球面点
    T      volume() const;                          // 体积
    T      surfaceArea() const;                     // 表面积
};

using Spheref = Sphere<float>;
using Sphered = Sphere<double>;
```

要点：

- `center + radius` 两个字段就是全部状态；
- 其余方法全是派生量：法线（第三节）、球面采样（第二节）、度量（第四节）。

## 二、参数方程：两个角度画遍全球

隐式方程能判定「谁在球面上」，却没法直接「枚举」球面上的点——想按点造网格、贴纹理，就需要**参数方程（显式表示）**。

### 2.1 球坐标参数方程

用两个角度可以把整个球面**完整遍历**：

$$
P(\theta,\varphi) = C + r\,(\sin\theta\cos\varphi,\ \sin\theta\sin\varphi,\ \cos\theta)
$$

写成分量形式更清楚：

$$
\begin{cases}
x = c_x + r\sin\theta\cos\varphi \\
y = c_y + r\sin\theta\sin\varphi \\
z = c_z + r\cos\theta
\end{cases}
\qquad
\theta \in [0,\pi],\quad \varphi \in [0,2\pi)
$$

### 2.2 极角 θ：从北极往下量

**$\theta$（polar angle，极角 / 天顶角）**——从 $+Z$ 轴向下量到的夹角：

- $\theta=0$ → 北极（$P=C+(0,0,r)$）；
- $\theta=\pi/2$ → 赤道（$XY$ 平面上的大圆）；
- $\theta=\pi$ → 南极（$P=C+(0,0,-r)$）。

$\cos\theta$ 给出 $Z$ 分量（**高度**），$\sin\theta$ 给出所在水平圆的**半径**——$\theta$ 一变，就在「沿经线爬上爬下」。

### 2.3 方位角 φ：绕赤道转一圈

**$\varphi$（azimuth angle，方位角）**——在 $XY$ 平面内绕 $Z$ 轴旋转的角度（以 $+X$ 轴为 0）：

- $\varphi=0$ → 指向 $+X$；
- $\varphi=\pi/2$ → 指向 $+Y$。

$\varphi$ 一变，就在「沿纬线东西转圈」。

### 2.4 两张图合起来读

**示意图（一）：过 $Z$ 轴的纵切面，看极角 $\theta$**

```
              +Z  (北极 θ=0)
               |
               |       ● P(θ, φ)
               |     / |
               |  r/  | r·cosθ  ← 高度
               | /θ   |
              (C)●────┴───────  赤道 (θ=π/2，XY 平面上的大圆)
               |   r·sinθ  ← P 所在水平圈的半径
               |
              −Z  (南极 θ=π)
```

**示意图（二）：从 $+Z$ 沿 $-Z$ 方向俯视赤道圆，看方位角 $\varphi$**（中心 ● 为球心投影）

```
          +Y
          ↑   φ=π/2
          |
   φ=π ●───●───●  φ=0 → +X
          |
          ↓   φ=3π/2
          −Y
```

把两张图合起来理解：先由 $\theta$ 决定「离北极多远」——$\cos\theta$ 给出高度、$\sin\theta$ 给出水平圈的半径；再由 $\varphi$ 决定「在这个水平圈上的哪个方向」。这正是参数方程中 $\sin\theta$ 控制「水平圈大小」、$\cos\theta$ 控制「高度」的来源。

> ⚠️ **采样均匀性有坑**：若把 $\theta$、$\varphi$ 都均匀取值，球面上的点**并不均匀**——纬线圈越靠近极点越短，同样的 $\Delta\varphi$ 挤着越多的点，极点附近会明显密集。想要球面均匀采样，应让 $\cos\theta$ 在 $[-1,1]$ 上均匀分布（逆变换采样），这是面试与实际写采样器时的经典细节。

## 三、法向量：径向即法向

球面的几何特性极好：**任意一点的法线都沿着「该点到球心的连线」方向**：

$$
\hat{n}(P) = \frac{P - C}{r} = \frac{P - C}{\|P-C\|}
$$

三条关键性质：

- 法线处处**垂直于球面**（径向方向恰好是球面切平面的法向）；
- 由球面点 $P$ 指向**外部**（背离球心），符合图形学「外法向」约定；
- 由于 $P$ 在球面上时 $\|P-C\|=r$，除以 $r$（或直接归一化）后即为**单位法向量**。

```cpp
Vec3<T> normalAt(const Vec3<T>& p) const {
    return (p - center).normalized();
}
```

上一篇的三角形求法线要两条边叉积，绕序一反法线就反向；球面法线则是**白送**的——一次减法加归一化，永远径向朝外、绝不会错。这就是「最对称曲面」的红利：处处长得一样，没有特殊点。

## 四、体积与表面积：洋葱模型

球体的两个经典度量公式。

**体积**：

$$
V = \frac{4}{3}\pi r^3
$$

**表面积**：

$$
A = 4\pi r^2
$$

```cpp
T volume() const      { return T(4.0 / 3.0) * T(M_PI) * radius * radius * radius; }
T surfaceArea() const { return T(4.0) * T(M_PI) * radius * radius; }
```

记忆关联：表面积 $A$ 恰好是体积 $V$ 对 $r$ 的导数——

$$
\frac{dV}{dr} = \frac{d}{dr}\!\left(\tfrac{4}{3}\pi r^3\right) = 4\pi r^2 = A
$$

这对应「**洋葱模型**」：半径加厚一层 $dr$，新增体积 $\approx$ 表面积 $\times\,dr$——往洋葱上再包一层皮，皮的体积就是表面积乘厚度。

> 回应开篇的阿基米德故事：外切圆柱（半径 $r$、高 $2r$）的体积是 $2\pi r^3$，恰为球体积的 $3/2$ 倍；表面积同样恰为 $3/2$ 倍（$6\pi r^2$ vs $4\pi r^2$）。一个比例统治两个度量，难怪阿基米德把它刻上墓碑。

## 五、使用示例

```cpp
using namespace gm;

// 构造：中心在原点，半径 2
Spheref sph(Vec3f(0, 0, 0), 2.0f);

// 体积与表面积
sph.volume();       // 4/3·π·8 ≈ 33.51
sph.surfaceArea();  // 4·π·4   ≈ 50.27

// 球面上一点 (2,0,0) 的法线 → 应为 (1,0,0)
Vec3f n = sph.normalAt(Vec3f(2, 0, 0));   // (1, 0, 0)

// 球坐标采样：θ=0 在北极 (0,0,r)；θ=π/2、φ=0 在 +X
Vec3f north = sph.pointOnSurface(0.0f, 0.0f);                  // (0, 0, 2)
Vec3f eqX   = sph.pointOnSurface(float(M_PI) / 2.0f, 0.0f);    // (2, 0, 0)
```

## 六、概念速览

### 核心公式速查

| 项目 | 公式 | 说明 |
|---|---|---|
| 隐式方程 | $(x-c_x)^2+(y-c_y)^2+(z-c_z)^2=r^2$，即 $\|P-C\|=r$ | 判定用平方，免开方 |
| 内外判定 | 平方值 $<r^2$ 内、$=r^2$ 面、$>r^2$ 外 | 推广：$d=\|P-C\|-r$ 即 SDF |
| 参数方程 | $P=C+r(\sin\theta\cos\varphi,\ \sin\theta\sin\varphi,\ \cos\theta)$ | 隐式 ↔ 显式的桥梁 |
| 极角 $\theta$ | $[0,\pi]$，从 $+Z$ 向下量 | $\cos\theta\to$高度，$\sin\theta\to$水平圈半径 |
| 方位角 $\varphi$ | $[0,2\pi)$，绕 $Z$ 轴，$\varphi=0$ 指向 $+X$ | 沿纬线转圈 |
| 法向量 | $\hat{n}=(P-C)/r$ | 径向朝外，白送 |
| 体积 / 表面积 | $V=\tfrac{4}{3}\pi r^3$，$A=4\pi r^2$ | $dV/dr=A$（洋葱模型） |

### 必记口诀

- **法线径向白送**：$(P-C)/r$，处处垂直、处处朝外——最对称曲面的红利。
- **内外判定用平方**：比 $\|P-C\|^2$ 与 $r^2$，一次点积搞定，省开方。
- **两角画球**：$\theta$ 管高度与水平圈大小，$\varphi$ 管水平朝向；先定纬线，再定经线。
- **均匀采样有坑**：$\theta,\varphi$ 均匀取值 → 极点密集；$\cos\theta$ 均匀才是球面均匀。
- **洋葱模型**：$dV/dr = A$，半径加厚一层，新增体积 = 表面积 × 厚度。
- **隐式 vs 显式**：球（方程）擅长判定与求交，网格（枚举）擅长光栅化绘制。
